# Política de seguridad

Durante el MVP se mantiene la rama principal más reciente.

No publiques claves, datos privados ni instrucciones de explotación en issues públicos. Contacta al mantenedor mediante los canales de seguridad del perfil del repositorio y comparte los pasos mínimos para reproducir el problema.

La API está pensada para ejecución local y escucha en loopback por defecto. No la expongas directamente a Internet. Antes de un despliegue público se necesitan autenticación, HTTPS, límites de frecuencia, aislamiento y revisión de configuración.

Nunca subas tokens, claves, corpus privados ni checkpoints con información personal.
