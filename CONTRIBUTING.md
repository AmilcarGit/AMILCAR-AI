# Contribuir

1. Abre un issue para discutir cambios grandes.
2. Mantén los cambios pequeños y centrados en un objetivo.
3. No elimines funcionalidades existentes sin explicar el motivo.
4. Añade o actualiza pruebas para los cambios de comportamiento.
5. Ejecuta pytest y npm run build dentro de apps/web antes de enviar cambios.
6. No incluyas secretos, datos privados, pesos grandes ni corpus sin licencia verificada.
7. Describe limitaciones y pasos para reproducir errores en el pull request.

Las contribuciones deben respetar la licencia del proyecto y los derechos de terceros.
